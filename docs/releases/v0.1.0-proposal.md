# Heartshop Goods v0.1.0 — proposed release notes

**Draft for owner review. No tag, GitHub Release or launch announcement.**

Heartshop Goods is a small MIT-licensed, self-hosted shop from Heartmade Studio.
It sells a physical product using PAYMOVE.io payments and Furgonetka.pl for
shipment processing and the merchant's invoice module. Heartshop passes invoice
data; it does not issue invoices itself.

This proposed first version includes a local simulation, server-side prices,
signed payment events, a seller panel, durable mail queue and merchant setup docs.
Indexing is opt-in, with generated public metadata and permanent noindex on
transaction/private pages. Read the hosting proposal before choosing a runtime.

Before upgrading a configured installation: back up and test restore, reapply
merchant configuration privately, rebuild the storefront, inspect the diff and
publish a mutually compatible config/PHP/HTML release atomically. Keep all
historical order data. Review `docs/edition-isolation.md` for remaining coupling.

Validation scope: automated offline suite and PHP 8.2–8.5 CI; inspect the eventual
release commit's checks before approving these notes. No merchant/provider UAT,
real money, email delivery, invoice issuance or hosting deployment is claimed.
No cart, inventory, variants, automatic refunds or autonomous payment agent.

Need implementation help? [Heartmade websites and shops](https://heartmade.pl/websites).
